# Loyalty Path — демо сайту

Головна і сторінка товару, зібрані з макета «Редизайн Loyalty Path» на React 19 + TypeScript + Vite.
Візуальний стиль — у дусі ocean-clo.com: білий фон, Montserrat, навігація й кнопки капсом із розрядкою, гострі кути, темно-синій для заголовків і цін.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статична збірка в dist/
npm run preview  # перегляд збірки
```

## Що всередині

- `/` — головна: слайдер-триптих під прозорою шапкою, біжучий рядок, плитки категорій, колекція з фільтром (стан у `?cat=`), готові образи, як працює пошив (дати рахуються від сьогодні), про бренд, соцмережі.
- `/product/:id` — сторінка будь-якого з 11 товарів: колір, розмір, підбір розміру за зростом і вагою, комплект, схожі моделі.
- Кошик (бокова панель на `<dialog>`) і обране зберігаються в `localStorage`.
- Форма зворотного дзвінка з валідацією українського номера. Оформлення замовлення не підключене, це демо.

## Структура

```
src/
  data/        товари, образи, розмірна сітка — єдине джерело даних
  store/       стан магазину: reducer + Context (кошик, обране, сповіщення)
  lib/         форматування цін і дат, хелпери посилань
  components/  шапка, футер, картка товару, кошик, Sheet (<dialog>), ескізи одягу
  pages/       home/ і product/ — секції сторінок, кожна зі своїм CSS Module
  styles/      токени дизайну і базові стилі
```

## Фото

У вихідному файлі були лише 9 фотографій: полузамок «Класика», білий джемпер і брюки.
Для решти моделей картка показує технічний ескіз силуету з позначкою «Ескіз, фото готуємо».
Щоб додати фото, покладіть його в `src/assets/photos/` і впишіть у `photos` відповідного товару в `src/data/products.ts`.

## Деплой

Сайт деплоїться на GitHub Pages через GitHub Actions ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)) при кожному push у `main`:
збірка з `BASE_PATH=/<назва-репозиторію>/`, копія `index.html` у `404.html`, щоб прямі посилання на `/product/...` відкривались, і публікація.

Локально перевірити саме таку збірку:

```bash
BASE_PATH=/loyalty-path/ npm run build
npm run preview -- --base /loyalty-path/
```

На хостингах з rewrite-правилами (Netlify, Vercel) `BASE_PATH` не потрібен; для Netlify вже є `public/_redirects`.
